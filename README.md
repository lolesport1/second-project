Git нужен чтобы сохранять версии проекта и не терять код. Главные понятия: Репозиторий это папка с проектом где есть скрытая папка .git. Коммит это просто сохранение (снимок) файлов на память. Ветка это отдельная линия разработки чтобы не ломать основной код. Удаленный репозиторий (обычно origin) это тот который лежит на сайте GitHub.

Основные команды которые я юзаю:

git init — создает репозиторий.
git status — показывает что изменилось.
git add . — подготавливает файлы к сохранению.
git commit -m "текст" — сохраняет изменения.
git push — отправляет код на гитхаб.
git pull — скачивает изменения оттуда.
git branch — показывает ветки.
git checkout -b название — создает новую ветку и переключает на нее.
git checkout main — переключает обратно на главную.
git merge название — вливает другую ветку в текущую.
